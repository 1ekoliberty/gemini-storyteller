# Рассказчик Gemini

Личный сервис озвучки для сайта ChatGPT. Код не содержит секретов.

## GitHub

Загрузите server.py, requirements.txt и render.yaml в корень репозитория. ZIP сначала распакуйте; сам архив в репозиторий не загружайте.

## Render — обычная форма Web Service

Выберите этот репозиторий. Language: Python 3. Build Command: `pip install -r requirements.txt`. Start Command: `uvicorn server:app --host 0.0.0.0 --port $PORT --no-access-log`. Instance Type: Free.

В Environment добавьте:

* `GEMINI_API_KEY` — ваш ключ Google, только здесь, не в GitHub.
* `ACCESS_SECRET` — используйте Generate для создания длинной случайной строки, минимум 32 символа, только буквы, цифры, `_` и `-`. Сохраните её как пароль.
* `GEMINI_MODEL` — `gemini-3.8-flash-tts` (модель можно изменить при необходимости).
* `GEMINI_VOICE` — точное имя понравившегося голоса из AI Studio; по умолчанию `Sulafat`. Для собственного voice ID вставьте его вместо имени.
* `PYTHON_VERSION` — `3.12.8`.

При желании `NARRATOR_STYLE` задаёт инструкцию по подаче. По умолчанию: тёплый рассказчик русских детских сказок.

Дождитесь Live. Откройте адрес Render: ответ должен быть `{"status":"ok"}`.

## ChatGPT

Имя: Рассказчик Gemini. URL: `https://ВАШ-СЕРВИС.onrender.com/ЗНАЧЕНИЕ_ACCESS_SECRET/mcp`.

Этот URL — секретная ссылка, дающая доступ к озвучке, поэтому его нельзя публиковать или присылать на открытых скриншотах. В форме подключения выберите аутентификацию None / «Нет», поскольку доступ ограничен случайным секретом в URL. Это простой вариант для одного пользователя, а не OAuth и не решение для публичной публикации. Если в вашей форме нет варианта «Нет», не создавайте подключение: понадобится другой способ авторизации.

При утечке URL замените ACCESS_SECRET в Render и обновите подключение. Ключ Google менять из-за утечки только этого URL не нужно; при утечке самого ключа отзовите ключ Google.

## Использование

Выберите плагин в новом чате. Попросите: «Озвучь этот текст без изменений одним рассказчиком». Сервис возвращает номер задания; через 20–30 секунд попросите проверить готовность. Когда готово, появится ссылка на WAV. Если чат не продолжает проверку самостоятельно, напишите «Проверь готовность».

## Ограничения

* Google получает текст для синтеза. Действуют лимиты и правила вашего проекта Gemini.
* На бесплатном Render после простоя первый запуск занимает около минуты. При ошибке подключения откройте главный адрес Render и повторите подключение после запуска.
* WAV и задания временные: удаляются через час при следующем обращении, а при остановке/перезапуске исчезают раньше. Скачивайте результат сразу. Отдельного постоянного хранилища нет.
* До 20000 символов, одна активная запись, до шести временных записей за час. Длинный текст делится на части; на стыках может меняться интонация.
* После перезапуска незавершённую запись нужно запускать заново.
* Команды не раскрывают ключ Google и URL подключения. Любой обладатель секретной ссылки всё же может расходовать вашу квоту.
* Локальная проверка не подтверждает доступность выбранной модели для вашего аккаунта. Сначала озвучьте один абзац на Render, проверьте тембр и полный текст, затем запускайте сказку.

Документация: https://ai.google.dev/gemini-api/docs/speech-generation и https://render.com/docs/free
